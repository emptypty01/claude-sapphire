# Claude Sapphire

让文字沉静，让思路清晰。

这是一份用于预览 **Claude Sapphire** 的 Markdown 示例。浅蓝灰色背景搭配宝石蓝点缀，适合阅读笔记、技术文档与日常写作。English and 中文可以自然地出现在同一段落中。

## 阅读与排版

好的排版让内容更容易被理解。你可以使用 **粗体强调重点**、*斜体补充语气*，也可以通过 `inline code` 标记命令、变量或接口字段。

> 写作是把模糊的想法，整理成清晰的表达。
>
> 留一点呼吸的空间，让阅读回到内容本身。

### 从想法到记录

- 用标题组织文档，建立清晰的阅读层级。
- 用列表拆解信息，让每个要点都容易找到。
- 用引用保留值得反复阅读的句子。

更多说明请查看 [GitHub 仓库](https://github.com/emptypty01/claude-sapphire)。

## 表格与代码

### 一眼看清关键信息

| 元素 | 视觉表现 | 适用内容 |
| --- | --- | --- |
| 正文 | 浅蓝灰背景、深色文字 | 长文阅读与日常笔记 |
| 链接 | 宝石蓝点缀 | 资料引用与文档导航 |
| 表格 | 圆角边框、交替底色 | 配置说明与信息对比 |
| 代码 | 等宽字体、语言标签 | 技术说明与代码片段 |

### 用代码表达逻辑

```java
public record Note(String title, boolean published) {
    public String summary() {
        return published ? title : "草稿 · " + title;
    }
}
```

## 提示与流程

> [!NOTE]
> 安装主题时，请将 `claude-sapphire.css` 与 `claude_fonts/` 一起复制到 Typora 主题目录。

> [!TIP]
> 字体会依照本机安装情况自动回退，也可以在自定义 CSS 中指定偏好的字体。

> [!IMPORTANT]
> 请保留原始 Markdown 文件，方便后续修改与复用。

> [!WARNING]
> 提示块和 Mermaid 需要当前 Typora 版本支持对应语法。

> [!CAUTION]
> 覆盖已有主题文件前，请备份自己的修改。

### 把思路串起来

```mermaid
flowchart LR

```
